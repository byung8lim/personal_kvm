# Personal KVM v0.1.1 변경 및 요구사항 대비 현황

## 기준과 버전 범위

- 기준 입력: `personal-kvm-v0.0.8.zip` 및 `최고의확장개발요청서.md`.
- 요청서의 공식 로드맵은 **v0.2.0, v0.3.0, v0.4.0, v1.0.0**입니다. 이번 **v0.1.1**은 해당 로드맵의 완료 버전으로 간주하지 않습니다.
- 실호스트 Rocky 9/10, VM 부팅, DNS, Traefik, 실제 네트워크 전환에 대한 성공 증적은 **없음**.

## 이번 버전에 실제 구현한 변경

1. `scripts/preflight_check.sh` 신설: `/etc/os-release`에서 Rocky 9/10 확인, CPU의 VT-x/AMD-V 및 Rocky 10 x86_64-v3 플래그를 점검. 누락 플래그별 실패 메시지 제공. 호스트 설정 변경 전 설치 스크립트에서 호출.
2. `backend/app/services/image_service.py`: 기존 이미지 레코드에 SHA-256이 저장되어 있다면, 재다운로드 파일의 다이제스트를 먼저 대조. 다르면 `.part` 제거, 기존 완성 이미지 보존 및 상태 ERROR 기록.
3. `tests/test_preflight_check.py`: 합성 OS/CPU 데이터로 9.x 허용, 10.x 플래그 실패, 비지원 OS 거부 시험.
4. 설치 프로그램 표시 버전 v0.1.1로 수정.

## 기존 코드에서 확인한 구현 및 제한

| 요구사항 | 상태 | 근거 / 제한 |
|---|---|---|
| Rocky 9/10 패키지 분기와 모듈형 libvirt | 기존 코드 있음, 실검증 전 | `scripts/install.sh`의 package probe, `virtqemud.socket` 등 탐색 |
| NetworkManager 브리지 | 기존 코드 있음, 실검증 전 | `scripts/setup_networks.sh`의 `nmcli` checkpoint. **외부망 브리지는 설정상 `virbr0`로 유지** |
| SPICE 제거/VNC/virtio | 검토 필요 | VM XML 생성기를 직접 사용하며 운영 호스트 그래픽 구동 테스트 없음 |
| Rocky 10 Cloud Image 카탈로그 | 기존 코드 있음 | `backend/app/core/init_db.py`. 다운로드 시 생성된 SHA-256은 **공식 원본 체크섬 검증 증거가 아님**. 원본 SHA-256 고정 검증 파이프라인은 미구현 |
| Traefik L4, ACME DNS-01, 미들웨어 | 미구현 | 요청서의 후속 Track 2 |
| Bind9 A/PTR 동기화 및 GC | 미구현 | 후속 Track 2 |
| Virtiofs, 스냅샷/백업 | 미구현 | 후속 Track 2 |
| `kvmctl apply -f cluster.yaml` | 미구현 | 후속 Track 3 |
| Prometheus/Grafana 관측성 | 미구현 | 후속 Track 3 |

## 재현 가능한 검사

```bash
bash scripts/preflight_check.sh
python3 -m unittest discover -s tests -v
bash -n scripts/preflight_check.sh scripts/install.sh
PYTHONPATH=backend python3 -m unittest discover -s backend/tests -v
```

- 작성 환경에서 `tests`의 6개 단위 테스트 통과.
- 백엔드 테스트는 일부 성공했으나 의존성(`pydantic_settings`, `sqlalchemy`, `passlib`) 미설치로 전체 검사가 완료되지 않음.
- 호스트 네트워크 전환은 SSH 단절 위험이 있으므로 콘솔 접근 및 NetworkManager 체크포인트 확인이 가능한 테스트 호스트에서 검증해야 함.

## 배포 유의사항

- 이 압축본의 설치/업그레이드는 운영 환경에 변화를 줍니다. 운영 장비에서 무검증 원클릭 실행을 권장하지 않습니다.
- 설치 전 `config/config.yaml`의 물리 NIC, IP, 게이트웨이 및 디스크 경로를 실제 값으로 검증하십시오. 코드의 예시 주소를 운영값으로 취급하지 마십시오.
- `scripts/preflight_check.sh`는 읽기 전용이므로 설치 전에 독립 실행할 수 있습니다.
