# One-shot install / network checkpoint correction (v0.2.3)

- Under `scripts/install.sh`, PKVM_ALLOW_NONINTERACTIVE_NETWORK defaults to 1. An explicit 0 restores manual confirmation.
- The bridge conversion retains the NetworkManager 180-second rollback checkpoint and validates bridge membership, IPv4 and default gateway before confirming.
- A second concurrent install fails with an explicit lock error rather than competing over system configuration.
- DNS server address assignment order was repaired.
- compute.yaml's public CIDR is validated against the actual host IPv4; mismatches fail with an actionable message.

## Validation boundary
Static regression tests and shell syntax checks do not prove that a real Rocky Linux 9/10 host can install every component. Use a local console for the first physical NIC bridge conversion; SSH can be interrupted. Full system service acceptance remains required.

## Command
`sudo bash scripts/install.sh`
