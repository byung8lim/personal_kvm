# personal-kvm v0.1.2 제한적 안정화 패치 현황

작성일: 2026-11-07

## 구현 완료 및 코드 증거

1. `backend/app/services/vm_provisioner.py`: cloud-init 설정 `manage_etc_hosts: false`로 변경. 기존 게스트 `/etc/hosts` 덮어쓰기를 방지하기 위한 변경이며 실제 Rocky/Ubuntu 이미지에 대한 부팅 검증은 필요하다.
2. 같은 파일: `qemu-img convert`, `resize`, `create` 실패 시 불완전하게 생성된 대상 디스크를 제거하도록 보상 처리 추가. 기존 파일이 이미 있으면 생성 전에 오류 처리하여 건드리지 않는다.
3. 같은 파일: cloud-init ISO 생성 명령 실패 시 부분 ISO 정리.
4. `backend/tests/test_vm_provisioner.py`: hosts 보존 설정과 디스크 부분 생성 실패의 파일 정리 회귀 테스트 추가.

## 테스트 결과

- `python -m compileall -q backend/app backend/tests` 통과.
- `PYTHONPATH=backend python -m unittest discover -s backend/tests -p 'test_vm_provisioner.py' -v`는 실행 환경에 `passlib` 패키지가 없어 테스트 모듈 로딩 단계에서 중단됨. 테스트 성공으로 기록하지 않는다.
- 실제 Rocky 9/10 및 libvirt 환경, UI E2E, DNS/NFS/Traefik 통합 검증은 수행하지 못했다.

## 미완료 사항

이 패치는 앞서 작성한 감사 결함 보완 및 확장기능 개발계획 **전체 구현본이 아니다**. P0 작업 상태 저널과 재시작 복구, NetworkManager 체크포인트, IP RANDOM/SERIAL, 공유볼륨 관리, Bind9 Split View, L4 HA/Failback, OS 이미지 갱신, 안전한 언인스톨 및 전체 Rocky 9/10 회귀 검증은 남아 있다. 테스트 및 운영 환경 없이 완료를 선언할 수 없다.

## 적용 주의

실서버 적용 전에 기존 v0.1.1 설치 파일과 데이터베이스, 이미지 및 설정을 백업하고 격리된 테스트 환경에서 검증해야 한다. 이 패치의 버전 표기는 파일 묶음 식별자이며 전체 개선계획 달성을 의미하지 않는다.
