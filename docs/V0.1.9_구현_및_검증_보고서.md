## 운영상 중요한 제한

1. 실제 DNS View는 질의 출발지마다 다릅니다. 서버에서 조회한 A/PTR 한 세트만으로 모든 네트워크의 정합성을 확인했다고 볼 수 없습니다.
2. L4 Failback은 30초 기본 제한 내 Standby 기존 세션이 종료되어야 성공합니다. 종료되지 않으면 Primary를 다시 비활성화하고 Standby 유지 절차를 시도하며, 실제 연결을 강제 종료하지 않습니다.
3. L4 단일 백엔드는 HA가 아닙니다. Runtime 조회는 가능하지만 Failback은 제공되지 않습니다.
4. L7 실시간 백엔드 건강 상태는 관리 API에서 아직 `unavailable`로 표시합니다. 운영 환경에서 별도 실제 요청/로그로 확인하십시오.
5. 설치 스크립트는 실제 호스트 네트워크·DB·서비스 설정을 변경합니다. 우선 전용 시험 서버에서 실행해야 합니다.
